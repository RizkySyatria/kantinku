# KantinKu

KantinKu adalah platform manajemen kantin kampus berbasis
mobile-first yang mengintegrasikan Point of Sale (POS),
persediaan, dan business analytics.

## Project

Mata Kuliah:
Capstone Project

## Target

UMKM/Kantin Kampus

## Roles

- Owner
- Cashier

## Technology Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- IndexedDB
- Vercel
- GitHub

## Main Features

- Authentication
- Point of Sale
- Product Management
- Inventory
- Sales History
- Reports
- Business Analytics
- Offline Transaction
- Data Synchronization
